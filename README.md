# Ultimate Align — landing page (design 3)

Static landing page for **Ultimate Align**, an After Effects panel for aligning groups,
resizing many layers at once and keeping shape strokes constant.

Design 3: dark only, a 3D opening where real panel screenshots fly in, a scroll-driven
tour of the panel, 18 animated examples and a "try it" playground.

## Live page

https://bigmisha87.github.io/ULTIMATE-ALIGN-LANDING-PAGE/

## View it locally

Open `index.html` in a browser (double-click works, no server needed), or turn on
GitHub Pages for this repository (Settings → Pages → Deploy from a branch → `main` / root).

## What is in here

- `index.html` — the whole page
- `assets/app.js`, `assets/app.css` — page script and styles
- `assets/hero3d.js` — the 3D opening (three.js, bundled locally, loaded on demand)
- `assets/panel/` — screenshots of the real panel
- `assets/posters/` — still frames shown while the animations load

The page has no price on purpose; every button just says "Buy now" and links to the Gumroad page.
